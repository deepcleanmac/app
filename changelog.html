Every DeepCleanMac release and what changed in it.

Version 1.7.4

  • ImprovedSafer cleaning for developers. Sign-ins, installed tools and data used by running apps are now left alone.

  • ImprovedHelp and support links have been updated.

October 19, 2026

Version 1.7.3

  • FixCleaning Power Logs no longer deletes any of macOS's live power databases; only old archived records are cleaned
  • NewOld macOS and xrOS debug files in Xcode Device Support are now cleaned, keeping the two newest of each
October 15, 2026

Version 1.7.2

  • FixUpdate copies waiting to install no longer show up as a second copy of the app in the Uninstaller
  • ImprovedUninstalls now also remove the app's crash-reporter folder and its folder in the macOS system cache
  • ImprovedUninstalling Claude Desktop now removes its "Claude-3p" folders
  • ImprovedSymantec, Broadcom and Alibaba Cloud Security software can only be removed with the vendor's own uninstaller
October 13, 2026

Version 1.7.1

  • FixOffline Spotify music is safe — Spotify keeps the songs you download for offline listening inside its cache folder, so cleaning that cache could delete your downloads. The Spotify cache is no longer cleaned.
  • Fix Prometheus metrics are no longer lost — the Prometheus write-ahead log was treated as a cache, but it holds recent metrics that haven't been saved anywhere else yet. It's now always left alone.
  • FixYour current iOS debug files stay — Xcode Device Support always keeps the two newest versions, but it counted them across every device type together. A newer watchOS or tvOS version could push out the iOS version you're still using. The two newest are now kept for each device type separately.
  • ImprovedSafer cleanup for developers — build folders in your projects were sometimes not recognised as holding files committed to Git, for example after a folder was renamed only by changing its capital letters. Those folders are now kept like any other folder with committed files.
  • ImprovedNo surprise iCloud downloads — when your projects folder is in iCloud Drive, the project scan now skips folders that are stored only in the cloud. Before, just scanning them made macOS download them.
  • ImprovedSafer uninstalls for Epic Games apps — uninstalling one app could also match the shared Epic folder in Application Support, which holds engines, assets and licence data used by other Epic apps. That folder is now always left alone.
  • NewMore developer files covered — the Cleaner now finds old visionOS debug files in Xcode Device Support, and cached Apple TV software updates next to the iPhone and iPad ones.
October 7, 2026

Version 1.7.0

  • FixCrash reports are saved again after a clean — cleaning your logs could remove the folder macOS saves crash reports in. macOS can't recreate that folder on its own, so new crash reports were quietly lost from then on. The old reports are still cleaned, but the folder now stays.
  • Fix Live Text keeps working after a clean — macOS keeps a small cache that powers text recognition in images, Live Text and parts of Spotlight. Clearing it while those were running could break them until the app was restarted. It's now always left alone, and it frees almost no space anyway.
  • ImprovedSafer cleanup for developers — build folders in your coding projects are now checked before they're offered for cleaning. A folder is kept if it holds its own Git repository, a deploy key, or files you've committed to Git. It's also kept whenever DeepCleanMac can't finish checking it.
  • NewCrash reports have their own category — they now appear as "User Crash Reports" in the Cleaner, separate from User Logs, so you can see what they take up and clean them on their own.

Version 1.6.8

  • FixSafer cleaning for R users — the R cache folder is no longer cleared. renv keeps its installed packages there and links every project to them, so emptying it left R projects unable to load their packages. The folder is now always left alone.

  • New Move a license to a new Mac yourself — if activation says the license is already in use, you now get a link to release it from the other Mac. Useful when that Mac was sold, erased or died, which is usually why you're activating a new one.
